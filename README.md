# TaskMate - Application de Gestion de Projets
TaskMate est une application Android pour faciliter la gestion de projets et de tâches. Elle permet aux utilisateurs de créer, de gérer et de suivre leurs projets et tâches de manière efficace.

## Description Générale
TaskMate offre une plateforme centrale pour gérer les projets, les tâches et les collaborations. Les utilisateurs peuvent créer des projets, ajouter des tâches, attribuer des responsables et suivre les progrès. L'application permet également la collaboration entre les membres d'une équipe pour travailler sur des projets communs.

## Fonctionnalités Principales
* **Gestion de Projets** : Les utilisateurs peuvent créer, modifier et supprimer des projets.
* **Gestion de Tâches** : Les utilisateurs peuvent créer, modifier et supprimer des tâches dans un projet.
* **Collaboration** : Les utilisateurs peuvent inviter d'autres utilisateurs à rejoindre un projet et attribuer des tâches à ces membres.
* **Suivi des Progrès** : Les utilisateurs peuvent suivre les progrès des tâches et des projets.
* **Notifications** : Les utilisateurs reçoivent des notifications lorsqu'une tâche leur est attribuée ou lorsqu'un projet est mis à jour.

## Technologies Utilisées
* **Kotlin** : Langage de programmation utilisé pour développer l'application.
* **Android** : Plateforme sur laquelle l'application est développée.
* **Firebase** : Utilisé pour l'authentification et le stockage des données.
* **Gradle** : Utilisé pour la gestion des dépendances et la construction de l'application.

## Guide d'Installation Rapide
1. **Cloner le Répertoire** : Cloner le répertoire Git de TaskMate sur votre machine locale.
2. **Configurer Firebase** : Configurer Firebase pour l'authentification et le stockage des données.
3. **Exécuter l'Application** : Exécuter l'application sur un émulateur ou un appareil Android.
4. **Lancer l'Application** : Lancer l'application et commencer à utiliser TaskMate pour gérer vos projets et tâches.
