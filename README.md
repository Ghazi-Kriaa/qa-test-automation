# TaskMate - Application de Gestion de Projets
TaskMate est une application Android pour faciliter la gestion de projets et de tâches. Elle permet aux utilisateurs de créer, gérer et suivre leurs projets et tâches de manière efficace.

## Description Générale
TaskMate offre une plateforme centrale pour gérer les projets, les tâches et les collaborations. Elle permet aux utilisateurs de créer des projets, d'ajouter des tâches, de les assigner à des membres de l'équipe et de suivre les progrès. L'application est conçue pour être intuitive et facile à utiliser, ce qui en fait un outil essentiel pour les équipes et les individus qui cherchent à améliorer leur productivité.

## Fonctionnalités Principales
* **Création de Projets** : Les utilisateurs peuvent créer de nouveaux projets et les gérer de manière efficace.
* **Gestion de Tâches** : Les utilisateurs peuvent créer, gérer et assigner des tâches à des membres de l'équipe.
* **Suivi des Progrès** : Les utilisateurs peuvent suivre les progrès des tâches et des projets.
* **Collaboration** : Les utilisateurs peuvent collaborer avec d'autres membres de l'équipe sur des projets et des tâches.
* **Notification** : Les utilisateurs reçoivent des notifications lorsqu'une tâche est assignée ou lorsqu'un projet est mis à jour.
* **Intégration avec Firebase** : TaskMate utilise Firebase pour l'authentification et le stockage des données.

## Technologies Utilisées
* **Kotlin** : Langage de programmation utilisé pour développer l'application.
* **Android** : Plateforme sur laquelle l'application est développée.
* **Firebase** : Plateforme utilisée pour l'authentification et le stockage des données.
* **Gradle** : Outil de construction utilisé pour gérer les dépendances et compiler l'application.
* **GitHub Actions** : Outil de continuous integration utilisé pour automatiser les tests et les déploiements.

## Guide d'Installation Rapide
1. **Cloner le Dépôt** : Cloner le dépôt Git de TaskMate sur votre machine locale.
2. **Configurer Firebase** : Configurer Firebase pour utiliser l'authentification et le stockage des données.
3. **Exécuter l'Application** : Exécuter l'application sur un émulateur ou un appareil physique.
4. **Lancer l'Application** : Lancer l'application et commencer à utiliser TaskMate pour gérer vos projets et tâches.
